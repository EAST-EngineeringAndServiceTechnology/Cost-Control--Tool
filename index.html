❓ Help
  1. Step 1 – Estimated (plan): In Budget + Time set planned cost, mfg days, shipping type, and schedule dates.
  2. Step 2 – Actual (later): When the item arrives / invoice comes, open Actual Costs, select the same category, enter real amount and actual mfg/ship days.
  3. Estimated values stay as the original plan. Actual values are filled at another time when you receive the item.
  4. Shipping: ⚡ Express 2w · ✈️ Flight 1.5m · 🚢 Sea 2–3m · 🚚 Local 2w.
  5. Currency risk: CHF · USD · EUR · EGP — set rates & risk % under Currency Risk. Costs/selling convert to base for profit.
  6. Data is saved in this browser. Use JSON export for backup.
